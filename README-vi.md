## Bắt Đầu Nhanh 🚀

### Windows (Dành Cho Máy Windows)
Người dùng Windows có thể tải gói cài đặt "One-click" trực tiếp từ GitHub Releases.
- [Tải gói One-click dành cho Windows](https://github.com/harry0703/MoneyPrinterTurbo/releases/latest) (Tải file đuôi `.7z`)

Sau khi giải nén, nhấn đúp vào `update.bat` để cập nhật mã nguồn mới nhất, sau đó nhấp vào `start.bat` để khởi động ứng dụng. Browser sẽ tự mở (khuyến khích dùng Chrome hoặc Edge).

### Chạy qua Docker (Dành cho macOS / Linux / Windows WSL)
Nếu bạn chưa cài Docker, hãy cài đặt Docker Desktop trước.

```shell
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
```
Mở trình duyệt truy cập: `http://127.0.0.1:8501`

### Cài Đặt Thủ Công (Môi Trường Cục Bộ - Python)
Dành cho người dùng macOS, Linux hoặc người dùng Windows muốn tự cài:
Yêu cầu Python 3.11 trở lên.

**1. Clone dự án**
```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
```

**2. Tạo môi trường ảo và cài dependencies (khuyên dùng `uv`)**
```shell
uv python install 3.11
uv sync --frozen
```
Hoặc dùng pip truyền thống:
```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**3. Chạy WebUI**
Windows:
```powershell
.\webui.bat
```
macOS/Linux:
```shell
sh webui.sh
```

**4. Chạy Service API (Tùy chọn)**
```shell
uv run python main.py
```
Truy cập tài liệu API qua `http://127.0.0.1:8080/docs`.

### Chế Độ Dòng Lệnh (CLI) Thuần Tuý ⌨️
Nếu không dùng qua giao diện WebUI, bạn có thể tạo video trực tiếp qua dòng lệnh CLI.
```shell
uv run python cli.py --video-subject "How AI is changing everyday life"
```

## Lồng Tiếng, Phụ Đề & Nhạc Nền 🎙️
- **Tổng hợp giọng nói (Voice Synthesis):** Mặc định WebUI sử dụng **Azure TTS V1** thông qua Edge TTS hoàn toàn miễn phí và không cần API. Bạn có thể chọn nhiều cấu hình khác (như Azure V2, SiliconFlow, v.v...) tuỳ theo nhu cầu cấu hình.
- **Tạo Phụ Đề (Subtitle Generation):** 
  - `edge`: Sử dụng nhãn thời gian từ TTS, tốc độ nhanh, không dùng GPU (mặc định).
  - `whisper`: Sử dụng AI offline nội bộ khi cần độ chính xác cao nhất (Sẽ tải mô hình tự động từ HuggingFace ở lần đầu sử dụng).
- **Nhạc nền:** Nằm ở thư mục `resource/songs` của dự án.
- **Font chữ phụ đề:** Nằm ở thư mục `resource/fonts`, bạn có thể chép font riêng vào.

## Các Lỗi Thường Gặp (FAQ) 🤔
- **Lỗi `RuntimeError: No ffmpeg exe could be found`:** Hệ thống thiếu cài đặt FFmpeg. Hãy tải FFmpeg và set cứng đường dẫn vào `config.toml` ở trường `ffmpeg_path = "..."`.
- **Lỗi tải mô hình Whisper:** Có thể do kết nối mạng tới HuggingFace lỗi. Hãy tải mô hình cục bộ và bỏ vào mục `models/whisper-large-v3`.
